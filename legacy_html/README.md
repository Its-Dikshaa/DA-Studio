# DA🌻 studio website

An original, responsive multi-page website for DA🌻, a UI/UX and development studio.

## Included pages

- Home
- Work archive and three individual concept case studies
- Services hub and individual pages for UX strategy, product design, web design/development, and brand systems/motion
- About
- Contact, project-enquiry form, and FAQ

## Preview locally

From this directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Lead form

The form is already marked up for [Netlify Forms](https://docs.netlify.com/manage/forms/setup/). When this folder is deployed on Netlify, project enquiries will be captured in the Netlify dashboard without adding a third-party form script. Replace `hello@da-studio.in` in `index.html`, `contact.html`, and `script.js` with the final business email before launch.

The concept project cards and client statements are deliberately illustrative; replace them with genuine project details and verified feedback before publishing.
